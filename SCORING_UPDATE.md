# Speed scoring update

- First correct answer received by the bot: 4 points.
- Second correct answer: 3 points.
- Third correct answer: 2 points.
- Every later correct answer: 1 point.
- Incorrect and unanswered: 0 points.
- 15-second answer timer retained.
- Old 100-point awards and streak bonuses removed.
- Sudden-death tiebreakers remain elimination-based (no points).
- Existing saved round records remain unchanged; new rounds use the new scale.

Upload SSKnowledge.py to the root of your GitHub repository and commit. Railway start command remains `python SSKnowledge.py`. Existing graphics and questions may remain unchanged.
