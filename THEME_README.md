# SS Knowledge Showdown — Navy & Silver Theme

Replace `SSKnowledge.py` in your GitHub repository with the file in this package. Upload the five PNGs either into an `assets/` folder (preferred) or alongside `SSKnowledge.py` in the repository root. Keep `questions.json` and `requirements.txt` at the root.

Railway Start Command: `python SSKnowledge.py`. Keep existing `DISCORD_TOKEN`, `GUILD_ID`, and persistent `DATA_DIR=/data` if configured.

All public status messages and private button acknowledgements now use consistent navy/silver-style Discord embeds with restrained gold highlights for milestones. Image banners are attached for lobby, questions, results, tiebreakers, and leaderboards. Discord's actual embed background and button colours are controlled by Discord; this theme uses embed accents and PNG artwork.

The minimum players remains 1 for testing; regular answers remain 15 seconds.
